6vg # SiDag — Sistem Informasi Asesmen Diagnostik Tiga Tingkat

Website platform asesmen diagnostik tiga tingkat (*Three-Tier Diagnostic Assessment*) untuk mengidentifikasi tingkat pemahaman dan miskonsepsi siswa secara akurat dan komprehensif.

## 🌟 Fitur Utama

- **Landing Page Interaktif**: Penjelasan metode three-tier (Tier 1: Pertanyaan Konsep, Tier 2: Tingkat Keyakinan/CRI, Tier 3: Alasan Jawaban).
- **Interactive Matrix Explorer**: Simulasi visual kombinasi 3 tier untuk membedakan Paham Konsep, Miskonsepsi, dan Tidak Paham.
- **Katalog Soal & Bank Asesmen**: Contoh asesmen diagnostik siap pakai dengan berbagai mata pelajaran.
- **Demo Asesmen & Live Simulator**: Uji coba langsung mekanisme pengerjaan asesmen 3 tingkat.
- **Dashboard Analitik Guru**: Visualisasi profil pemahaman kelas, distribusi miskonsepsi, dan ekspor laporan.
- **Kalkulator Miskonsepsi Cepat**: Alat interaktif untuk menganalisis status pemahaman siswa seketika.

## 🚀 Cara Menjalankan

### Menggunakan Node.js
```bash
# Jalankan server lokal
node serve.js
```
Akses di browser: `http://localhost:3000`

### Tanpa Server
Buka file `index.html` langsung di browser pilihan Anda.
